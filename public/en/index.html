HOW IT WORKS

Why use cm/360?

In-game sensitivity numbers use different scales across games. cm/360 measures the physical mouse distance required for a full 360° turn, which makes cross-game comparison more meaningful.

cm/360 = 2.54 × 360 ÷ (DPI × sensitivity × yaw)

ADS, scope multipliers, FOV, acceleration and input handling can still change how a setting feels. Use the result as a starting point and fine-tune in game.

DATA NOTE

About conversion coefficients

This version uses widely used sensitivity/yaw coefficients for the supported games. PUBG is excluded for now because its sensitivity slider should not be treated as one simple linear coefficient without separate validation.
