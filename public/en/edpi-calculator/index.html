GUIDE

What is eDPI?

eDPI is DPI × in-game sensitivity. It is useful for comparing settings inside the same game.

eDPI = DPI × sensitivity

Example: 800 DPI × 0.4 = 320 eDPI. If you move to 1600 DPI and want the same eDPI, use 0.2 sensitivity.

For different games, use cm/360 instead because sensitivity scales differ.
