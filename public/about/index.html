GameTools KR / GameTools KR 소개

무엇을 만드는 사이트인가?

GameTools KR는 FPS 게임에서 자주 필요한 감도 변환, eDPI, cm/360 계산을 빠르게 확인할 수 있도록 만든 무료 브라우저 도구 사이트입니다.

현재 VALORANT, Counter-Strike 2, Apex Legends, Overwatch 2의 선형 hip-fire 감도 변환과 전용 계산기를 제공합니다.

개발 원칙

  • 계산식과 한계를 숨기지 않고 공개합니다.
  • 사용자 입력은 가능한 한 브라우저 안에서 처리합니다.
  • 새 기능은 정확성을 확인한 뒤 추가합니다.
  • 검색용 복제 페이지보다 실제로 쓸 수 있는 독립 도구를 우선합니다.

오류 제보와 기능 제안

계산 오류나 추가했으면 하는 기능이 있다면 GitHub 저장소의 Issues를 사용할 수 있습니다.
