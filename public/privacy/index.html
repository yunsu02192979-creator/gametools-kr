현재 사이트가 처리하는 정보

감도, DPI, 프로필 이름 등 계산기에 입력한 값은 계산을 위해 브라우저에서 처리됩니다. 홈의 설정 저장 기능은 브라우저의 localStorage를 사용하며, 브라우저 데이터를 삭제하면 저장된 설정도 사라질 수 있습니다.

Cloudflare Web Analytics

사이트 사용량과 성능을 파악하기 위해 Cloudflare Web Analytics를 사용합니다. 이 분석 도구를 통해 페이지뷰, 방문, 경로, 유입 출처, 국가, 기기 유형과 같은 집계 지표를 확인할 수 있습니다.

Cloudflare는 Web Analytics가 방문자를 개별적으로 추적하지 않고 개인 데이터를 수집·사용하지 않는다고 설명합니다.

광고

현재 GameTools KR에는 광고 코드가 설치되어 있지 않습니다. 향후 광고나 다른 외부 서비스가 추가되어 쿠키 또는 추가 데이터 처리가 발생하면 이 안내도 그에 맞게 수정합니다.

변경

사이트 기능이나 외부 서비스가 변경되면 이 페이지의 내용을 함께 업데이트합니다.
